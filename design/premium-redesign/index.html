BOX · Design direction 01 · Ringside

Premium, cohesive,
one job per screen.

Each tab is built from the same four parts: a header that names the screen, one red hero holding the main action, a tool grid with color-coded icons, and a compact history list. Condensed italic display type, the ring-rope pattern and the floating glass tab bar carry the BOX identity from screen to screen. Every number shown comes from real logged data, so there's no XP, no leaderboard and no made-up grades.

03 · SystemThe rules that hold it together. They map onto BoxStyle.swift / BoxComponents.swift

Screen anatomy: same order on every tab

01

Header

An italic condensed title, one line saying what the screen is for, and at most one glass utility button.
02

Red hero

The one main action on the screen. It's the only place the red gradient appears.
03

Tools / stats

A 2-up or 3-up grid of charcoal cards with tinted icon wells, all built from the same component.
04

History

Compact grouped rows inside one card. Details open on tap instead of expanding in place.

Principles

One red moment per screenThe hero gradient only marks the main action. If everything is red, nothing stands out.

Color means somethingPillar colors identify a type of activity and never decorate. Learn them once and they read the same on every screen.

Numbers are the heroesLarge condensed numerals for time, calories, rounds and hits. Labels stay small, uppercase and muted.

Glass floats, charcoal holds contentGlass is used for the tab bar and utility buttons. Cards stay solid so text is easy to read (this matches DESIGN_RULES).

Big, low controls during trainingSession screens put 56–84 pt controls near the bottom so you can hit them with gloves on.

Real data, earned payoffStreaks and totals come from saved sessions. Recaps celebrate work you actually did, never made-up scores.
